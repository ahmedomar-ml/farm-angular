# نظام إدارة المزرعة — Angular + Node.js + SQLite

## التشغيل على جهازك (3 خطوات)
المطلوب: Node.js نسخة 22.5 أو أحدث (`node -v`).

```
npm install
npm run build:app     # يبني الفرونت وينسخه في server/public
npm run server        # السيرفر على http://localhost:3000
```

افتح http://localhost:3000 واضغط «حساب مزرعة جديد». أي حد يقدر يسجّل مزرعته بنفسه (اسم المزرعة + رقم التليفون + كلمة مرور)، وبياناته معزولة تماماً عن باقي المزارع.

## الدخول
- بالتليفون وكلمة المرور، من غير إيميل.
- الدخول بيفضل محفوظ 180 يوم على نفس الجهاز، والمتصفح بيعرض حفظ كلمة المرور.
- المدير يضيف الفريق (مهندس / مشرف / عامل / دكتور / محاسب / أمين مخزن)، وكل واحد يدخل برقمه.

## الوكلاء (Multi-Agent)
6 وكلاء بيتواصلوا عن طريق لوحة رسائل في الداتا بيز، وبيشتغلوا لما المدير يضغط «شغّل الوكلاء الآن» وكمان تلقائياً كل 6 ساعات (`AGENTS_INTERVAL_MIN`، وللإيقاف `AGENTS_AUTORUN=0`):

| الوكيل | شغله | بيبلّغ مين |
|---|---|---|
| وكيل الحضور | مين مسجّلش حضور، غياب 3 أيام ورا بعض | الرواتب، الإدارة |
| وكيل الصحة والنافق | نسبة النافق اليومية مقابل الحد، والاتجاه | المخزون، المدير والمهندس والدكتور |
| وكيل التحصينات | مواعيد التحصين حسب عمر الدورة | المخزون، المدير والمهندس والدكتور |
| وكيل المخزون | العلف (كام يوم يكفي) والأدوية، ويقترح أمر شراء (عاجل لو فيه إنذار نافق) | المنسّق |
| وكيل الرواتب | يحسب الراتب = أيام الحضور × اليومية − الخصومات − السلف ويقترح الصرف | المنسّق |
| المنسّق | ملخص يومي وتذكير بالمقترحات المنتظرة | المدير |

**القاعدة:** الوكلاء بيقترحوا وبيحذّروا بس. صرف الرواتب والشراء مش بيحصلوا إلا بعد موافقة المدير من تبويب «الوكلاء»، والموافقة على الرواتب بتسجّل الصرف في «صرف الرواتب» ومش بتتكرر لنفس الشهر.
الإعدادات (حد النافق، أيام العلف، حد الدواء، ساعة الحضور، يوم الرواتب) من نفس التبويب.

**المساعد (اختياري):** لو حطيت `ANTHROPIC_API_KEY` في بيئة السيرفر (واختيارياً `ANTHROPIC_MODEL`) يقدر المدير والمهندس والمحاسب يسألوا أسئلة حرة عن المزرعة، وهو للقراءة فقط ولا ينفذ أي إجراء. من غير المفتاح بيرجّع ملخص المزرعة.
المنطقة الزمنية: `FARM_TZ` (الافتراضي Africa/Cairo).

لإضافة وكيل جديد: اكتب دالة جديدة في `server/agents.js` داخل `FNS` وضيفها في `ORDER` و`AGENTS`.

## الداتا بيز
- SQLite في الملف `server/data/farm.db` (متغير `DB_FILE` لتغيير المكان).
- نسخة احتياطية تلقائية كل يوم في `server/data/backups` (آخر 14 نسخة).
- زرار «نسخة احتياطية» للمدير بينزّل ملف JSON بكل بيانات مزرعته.
- **احفظ فولدر `server/data` دايماً.** لو السيرفر على استضافة بتمسح الملفات عند إعادة التشغيل (زي أغلب الاستضافات المجانية) هتضيع البيانات، فاستخدم سيرفر بقرص دائم (VPS) أو شغّله على جهاز المزرعة.

## الأمان
- كلمات المرور متشفرة (scrypt) ومش بتتخزن نصاً.
- الصلاحيات بيفرضها السيرفر نفسه، مش الفرونت: العامل مش بيشوف غير عنبره، والملاحظات بتظهر للجهة المحددة بس، والشكاوى للمدير بس.
- حماية من تخمين كلمة المرور (8 محاولات / 15 دقيقة).
- استخدم HTTPS على أي سيرفر عام.

## الصلاحيات
المدير له كل شيء ويعدّل صلاحيات كل وظيفة من تبويب «الصلاحيات» (عرض / إضافة / تعديل / حذف لكل قسم).
القيم الافتراضية في `server/schema.js`.

## نشر الفرونت على GitHub Pages
الـ workflow بيبني الفرونت فقط. علشان يشتغل لازم السيرفر يكون على رابط عام، وتكتبه في `API_BASE` داخل `src/app/store.service.ts`.
